# Remote SDT — Diagnostic Replay PoC

建機ロガーのセンサーデータを、簡易3Dショベル・グラフ・アラートと同一時刻で再生する1画面プロトタイプです。バックエンドはなく、10秒分（100 ms間隔）のモックログをブラウザ内で生成します。

## 起動方法

Node.js 20.19以上（または22.12以上）がインストールされたPCで、このフォルダーをターミナルから開きます。

```bash
npm install
npm run dev
```

ターミナルに表示される `Local:` のURL（通常は `http://localhost:5173/`）を、ChromeやEdgeで開いてください。終了するときはターミナルで `Ctrl+C` を押します。

別のPCやスマートフォンから同じLAN内で確認する場合は、`Network:` に表示されたURLを開きます。OSやルーターのファイアウォールで5173番ポートが遮断されている場合は、アクセスを許可してください。

### 画面上で確認できる操作

1. 画面下部左側の黄色い **▶** を押すと、10秒間のログ再生が始まります。
2. **0.5× / 1× / 2×** で再生速度を切り替えられます。
3. 下部タイムラインの丸いノブをドラッグすると、任意の時刻へシークできます。
4. 3Dビューをドラッグすると視点回転、マウスホイールでズームできます。
5. 5.2秒付近で油圧グラフが急上昇し、E123アラート、タイムラインマーカー、3D作業機の赤色ハイライトが同時に表示されます。

本番相当の静的ファイルを確認したい場合は、次のコマンドを実行してから、表示されたURLを開きます。

```bash
npm run build
npm run preview
```

> `npm install` が403エラーになる場合は、利用中のネットワークや社内npmレジストリの設定で npmjs.org へのアクセスが許可されているか確認してください。本リポジトリのソースだけでは依存パッケージを同梱していないため、初回起動時にはパッケージの取得が必要です。

## ファイル構成

```text
src/
├── App.tsx            # 1画面UI、再生ループ、タイムライン
├── Excavator.tsx      # Three.js基本形状によるショベルと各Joint
├── PressureGraph.tsx  # uPlotの油圧グラフと同期カーソル
├── data.ts            # 100 msモックログと線形補間
├── store.ts           # Zustandのマスタークロック
├── styles.css         # 画面スタイル
└── main.tsx           # エントリーポイント
```

## 実データ・GLBへの置き換え

- `data.ts` の `LogSample` を実ログのスキーマに合わせ、APIやファイル読み込み後に同じ秒単位へ正規化します。すべての表示はZustandの `currentTime` だけを参照する構成を維持してください。
- 不規則なサンプリング周期のログでは、時刻の前後サンプルを二分探索し、現在の `sampleAt()` と同様に補間します。角度の折り返し（359°→0°）は最短角度補間に変更します。
- GLBは `@react-three/drei` の `useGLTF` で読み込み、モデル内の Boom / Arm / Bucket / Swing のノードへ補間済み角度を設定します。ノード名と回転軸、原点位置を事前にモデル制作側と揃えるのが重要です。
- アラートは実ログの開始・終了時刻をイベント配列として扱い、タイムラインマーカー、詳細表示、対象ノードのマテリアルを同じイベントから駆動します。
